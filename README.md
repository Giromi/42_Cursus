# 💻 42 Seoul Robotics & Computer Systems Projects

> Building a strong software engineering foundation for robotics through the 42 Seoul Common Core curriculum.

---

## 📖 Overview

This repository summarizes my projects completed during the **42 Seoul Common Core** curriculum.

Unlike traditional programming courses, 42 focuses on developing software from scratch with minimal external libraries. Through these projects, I gained practical experience in low-level programming, operating systems, networking, concurrent programming, graphics, and software architecture.

These experiences have become the computer science foundation supporting my work in **robotics, autonomous systems, and embedded software**.

---

# 🎯 Objectives

- Build software without relying on external libraries
- Understand computer systems from the operating system level
- Develop efficient algorithms and data structures
- Learn concurrent and network programming
- Improve software architecture and debugging skills
- Apply software engineering principles to robotics systems
